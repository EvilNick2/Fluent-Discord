# Fluent Discord
A Windows 11 theme for Discord

## Download
* From [Releases](https://github.com/EvilNick2/Fluent-Discord/releases/latest)
  * `Fluent-Discord.theme.css` will automatically update with new releases
  * `Fluent-Discord-static.theme.css` if you prefer to manually update to each release
* [Github.io link](https://evilnick2.github.io/Fluent-Discord/Fluent-Discord.theme.css) (Right-click > Copy Link)

### Optional Extras
* [EmojiReplace](https://betterdiscord.app/theme/EmojiReplace) theme by DevilBro to get Windows 11 emoji on Discord

## Getting Help
* Check the [FAQ](https://github.com/EvilNick2/Fluent-Discord/wiki/FAQ) first
* All options are documented on the [wiki](https://github.com/EvilNick2/Fluent-Discord/wiki)
* Report bugs by opening an [issue](https://github.com/EvilNick2/Fluent-Discord/issues)
